Architecture Decision Records (ADRs) capture consequential technical decisions and their
tradeoffs. Accepted records remain unchanged; later decisions supersede them with a new ADR.

## Record format

Each ADR should include a title, status, date, context, decision, and consequences. Use
`Proposed`, `Accepted`, `Superseded`, or `Rejected` as the status. The long-term filename
and numbering convention is **TBD**; existing filenames are retained for compatibility.
